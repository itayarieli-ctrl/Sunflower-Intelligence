# Evinature BD Intelligence Platform - Product Overview

## 1. Executive Summary

The Evinature BD Intelligence Platform is a comprehensive market intelligence system that enables strategic partnership decisions across four interconnected domains:

- **Influencer Intelligence** - Deep profiles of health advocates with IBD relevance
- **Organization Intelligence** - Global IBD patient organizations and medical societies
- **Geographic Intelligence** - Country-by-country market entry strategies
- **Event Intelligence** - Industry conferences and awareness campaigns

The platform provides enterprise-grade scoring, safety assessment, and research automation to identify, evaluate, and prioritize potential partners.

## 4. Scoring System

### 4.1 Six-Dimensional Scoring Model

Each influencer is evaluated across six dimensions:

| Dimension | Weight (Default) | Description |
|-----------|-----------------|-------------|
| **Relevance** | 25% | IBD/gut health topic alignment |
| **Reach** | 20% | Audience size and engagement potential |
| **Partnership Readiness** | 15% | History of brand collaborations |
| **Competition** | 15% | Conflicts with competitors (ZOE, etc.) |
| **Brand Safety** | 15% | Geopolitical stance and reputation |
| **Strategic Fit** | 10% | Long-term alignment with Evinature |

### 4.2 Weighted Score Calculation

```
Weighted Score = (Relevance × W1 + Reach × W2 + Partnership × W3 + 
                  Competition × W4 + Brand Safety × W5 + Strategic Fit × W6) / 100
```

Where W1-W6 are configurable weights that must sum to 100%.

Each dimension score is 0-100, with associated:
- **Confidence Level** (high/medium/low)
- **Reasoning** (AI-generated explanation)

### 4.3 Visualization

- **RadarChart6D** - Radial bar chart showing all 6 dimensions
- **Score Bars** - Horizontal progress bars with expandable reasoning
- **Weighted Total** - Central numeric display (0-100)

## 5. Verdict System

### 5.1 Verdict Decisions

| Verdict | Meaning | Color |
|---------|---------|-------|
| **PRIORITY_PARTNER** | Ideal partner - fast-track engagement | Gold |
| **CLEAR_YES** | Strong candidate - proceed | Green |
| **CONDITIONAL** | Requires additional due diligence | Yellow |
| **CAUTION** | Significant concerns - careful evaluation | Orange |
| **NO** | Not recommended for partnership | Red |
| **HARD_NO** | Absolute rejection - do not engage | Dark Red |

### 5.2 Verdict Determination Logic

The verdict is determined through a hierarchical priority system:

1. **VETO Gate** → If `veto_triggered = true` → `HARD_NO` (Geopolitical driver)
2. **Anti-Israel Flag** → If `ANTI_ISRAEL` in red flags → `HARD_NO` (Geopolitical driver)
3. **Hostile Flag** → If `HOSTILE` in red flags → `HARD_NO` (Company Sentiment driver)
4. **Priority Check** → If `ADVOCATE + PRO_ISRAEL` with no red flags → `PRIORITY_PARTNER` (Combined driver)
5. **Competition Block** → If `COMPETITOR` flag or competition score = 0 → `NO` (Business driver)
6. **Orange Flag Cap** → If `SENSITIVE/INVESTIGATE` flags → Maximum `CONDITIONAL`
7. **Score Thresholds**:
   - ≥75: `CLEAR_YES`
   - ≥60: `CONDITIONAL`
   - ≥45: `CAUTION`
   - <45: `NO`

### 5.3 Flag System

| Flag Type | Examples | Impact |
|-----------|----------|--------|
| **Green Flags** | `ADVOCATE`, `PRO_ISRAEL` | Positive indicators |
| **Orange Flags** | `SENSITIVE`, `INVESTIGATE` | Requires caution |
| **Red Flags** | `ANTI_ISRAEL`, `HOSTILE`, `COMPETITOR` | Blocking issues |

## 6. Cost Estimation Engine

### 6.1 Formula

```
Estimated Cost = (Followers / 1000) × Base CPM × Engagement × Platform × Region
```

### 6.2 Multipliers

**CPM Tiers (by audience size):**
| Tier | Followers | CPM |
|------|-----------|-----|
| Nano | 1K-10K | $15 |
| Micro | 10K-100K | $10 |
| Mid | 100K-500K | $6 |
| Macro | 500K-1M | $4 |
| Mega | 1M+ | $2.50 |

**Platform Multipliers:**
- YouTube: ×1.5
- TikTok: ×1.2
- Instagram: ×1.0
- Twitter: ×0.8
- Facebook: ×0.9

**Region Multipliers:**
- Americas: ×1.4
- Northern Europe: ×1.3
- Western Europe: ×1.2
- Southern Europe: ×1.0
- Eastern Europe: ×0.8

**Output:** Range (±20%) with breakdown explanation

## 10. Security & Access Control

### 10.1 Role-Based Access

| Role | Capabilities |
|------|--------------|
| **Admin** | Full access, user management, weight settings |
| **Moderator** | Update entities, import data |
| **User** | Read access, notes, research |

### 10.2 Row-Level Security

All tables protected with Supabase RLS policies:
- Public read access for most entity data
- Authenticated insert for imports
- Moderator/Admin update permissions
- Admin-only delete for sensitive tables

### 10.3 Geopolitical Gate

Critical brand safety mechanism:
- `CLEARED` - Safe to engage
- `CAUTION` - Requires review
- `BLOCKED` - VETO triggered
