# Skills מוכנים ל-Lovable workspace

הקבצים בתיקייה הזו הם skills מוכנים לפריסה ל-workspace של Lovable.

## דרך פריסה — GitHub sync (מומלץ)

1. הפעל GitHub sync בפרויקט Lovable → נעץ אותו לרפו הזה
2. הקבצים תחת `skills/` בשורש הרפו יזוהו אוטומטית כ-skills
3. שים לב: התיקייה כאן היא `skills-קלוד/` כי שם קובץ עברי נדרש
   בהעדפות המשתמש. לפני הסנכרון, שנה שם התיקייה ל-`skills/` (או
   העתק את התוכן לתיקיית `skills/` בשורש).

## דרך פריסה — MCP

כשהקונקטור של Lovable פעיל בשיחה, הרצה של `create_workspace_skill`
עם הפרמטרים:
  - workspace_id: E2yEcBUG95ByH0SbuHTG
  - name: מהתוכן של frontmatter
  - description: מהתוכן של frontmatter
  - content: תוכן ה-md בלי ה-frontmatter

## דרך פריסה — העתקה ידנית

Lovable → Workspace Settings → Skills → New Skill.
להעתיק את התוכן ישירות.
